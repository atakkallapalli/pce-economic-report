# PCE Economic Report

Python toolkit for downloading, analyzing, and visualizing Personal Consumption Expenditures (PCE) data from [FRED](https://fred.stlouisfed.org/) (Federal Reserve Economic Data).

## Overview

This project produces a comprehensive economic report on PCE data, including:

- **Headline vs. Core PCE inflation** (YoY comparison with Fed 2% target)
- **Multi-horizon inflation analysis** (MoM annualized, 3-month, 6-month, 12-month)
- **Nominal and Real PCE** levels and growth rates
- **Component breakdown** (Durable Goods, Nondurable Goods, Services)
- **Long-run historical perspective** (1960-present with recession shading)
- **Monthly inflation volatility** (24-month bar chart)

## FRED Series Used

| Series ID | Description |
|-----------|-------------|
| `PCE` | Personal Consumption Expenditures (Billions $, SAAR) |
| `PCEPI` | PCE Price Index (2017=100) |
| `PCEPILFE` | Core PCE Price Index excl. Food & Energy (2017=100) |
| `PCEC96` | Real PCE (Billions of Chained 2017 $, SAAR) |
| `PCEDG` | PCE: Durable Goods (Billions $, SAAR) |
| `PCEND` | PCE: Nondurable Goods (Billions $, SAAR) |
| `PCES` | PCE: Services (Billions $, SAAR) |

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Download latest data from FRED (no API key required)
python download_data.py

# 3. Run analysis and generate charts
python analyze_pce.py
```

Charts are saved to `output/charts/` and a JSON summary of key statistics is written to `output/stats.json`.

## Running Tests

```bash
pip install -r requirements.txt   # includes pytest
pytest -v
```

Tests use synthetic data and mocked network calls — no FRED access required.

## Generated Charts

1. **Headline vs. Core Inflation** -- YoY comparison since 2015
2. **Multi-Horizon Dashboard** -- 3m, 6m, 12m annualized (headline & core)
3. **Nominal PCE Level & Growth** -- Dual-axis: level + YoY %
4. **Real PCE** -- Chained 2017 dollars with growth overlay
5. **Component Growth** -- Durables, Nondurables, Services YoY
6. **Composition** -- Pie chart + historical stacked area
7. **Long-Run History** -- 1960-present with NBER recession shading
8. **Monthly Bars** -- Last 24 months MoM annualized

## Notes

- **No FRED API key required.** Data is downloaded via FRED's public CSV endpoint.
- The `data/` and `output/` directories are git-ignored since they can be regenerated by running the scripts.
